# M2 구현 스펙: CLI TUI (packages/cli)

> 설계: [architecture.md](../architecture.md) §7.1, [protocol.md](../protocol.md) §1. 계약 파일: `packages/cli/src/agent/types.ts`(고정, 두 작업자가 공유).

## 0. 공통
- TypeScript strict, ESM, Node ≥ 22. 런타임 검증은 zod. 테스트는 vitest. `pnpm --filter perdix build/test/lint/typecheck` 통과.
- ACP SDK: `@agentclientprotocol/sdk` 1.7 (`@perdix/protocol`이 재수출). 진입: `client({ name: "perdix" }).onRequest("session/request_permission", …).onNotification("session/update", …).connectWith(ndJsonStream(stdinOfServer, stdoutOfServer), async (ctx) => …)`. 정확한 시그니처는 `node_modules/.pnpm/@agentclientprotocol+sdk*/.../dist/acp.d.ts`에서 확인한다.
- 서버 발견 순서: `PERDIX_SERVER`(실행 파일 경로 또는 공백 구분 명령) → PATH의 `perdix-server` → 저장소 개발 모드(`<repo>/server/pyproject.toml`이 있으면 `uv run --project <repo>/server perdix-server`). 서버 stderr는 CLI stderr로 그대로 흘린다(`--debug`가 아니면 파일 `~/.perdix/logs/cli-<pid>.log`로 보낸다).
- 배포 방식(architecture.md §8-1)은 "uv tool install 권장"으로 두고 진행한다. 단일 바이너리는 보류.

## 1. 작업 A — `src/agent/` (ACP 클라이언트 계층, UI 비의존)
- `spawn.ts`: 서버 프로세스 기동(`child_process.spawn`, stdio pipe), 발견 순서 구현, 종료 감지.
- `connection.ts`: `connectWith`로 연결, `initialize`(clientCapabilities: `fs: {readTextFile: false, writeTextFile: false}`, `elicitation.form` 광고는 M3), `newSession` / `loadSession` / `listSessions` 래핑.
- `session.ts`: `AgentSession implements SessionHandle`. `session/update` → `AgentEvent` 변환(types.ts 주석의 매핑). `session/request_permission` → 등록된 핸들러로 전달, 없으면 `reject_once`. `prompt()`는 `turn_started`를 먼저 emit하고 응답에 `turn_ended`를 emit한다. `cancel()`은 `session/cancel` 알림.
- `headless.ts`: `perdix -p "<prompt>" [--json]` 비대화형. 서버를 `--permission-mode deny`(또는 `--permission-mode` 인자 전달)로 띄우고, 이벤트를 `--json`이면 NDJSON으로, 아니면 텍스트로 stdout에 출력. 종료 코드: end_turn 0, 그 외 1.
- `main.ts`: 인자 파싱(`-p`, `--json`, `--cwd`, `--mode`, `--model`, `--resume <id>`, `--list`, `--permission-mode`, `--server <cmd>`, `--debug`, `--version`). `-p`가 없으면 `ui/App`을 렌더(작업 B가 `ui/index.ts`에 `renderApp(handle, opts)`를 내보낸다. 없으면 임시로 텍스트 출력).
- 테스트: 가짜 ACP 에이전트를 **in-process**로 붙여(SDK의 `agent()` 앱 또는 간단한 ndjson 스트림 페어) `AgentSession` 변환을 검증. 그리고 Python 서버를 실제로 띄우는 통합 테스트 1개(`uv run --project ../../server perdix-server --provider fake --fake-script ../../server/tests/fixtures/demo.json --db <tmp>`): prompt → 이벤트 순서(agent_text, tool_call, tool_call_update completed, usage, turn_ended end_turn) 검증. 서버가 없으면 skip이 아니라 **fail**.

## 2. 작업 B — `src/ui/` (Ink 8 + React 19)
- `index.tsx`: `renderApp(handle: SessionHandle, opts: { listSessions?: () => Promise<SessionListItem[]> })`.
- 컴포넌트:
  - `Transcript`: 완료된 메시지/도구 카드는 `<Static>`으로 내보내고, 진행 중인 것만 동적 영역에 둔다(통합 터미널 깜빡임 방지).
  - `ToolCard`: 제목, kind 아이콘, 상태(pending/in_progress/completed/failed), 내용 접기/펼치기(기본 접힘, 최근 1개는 펼침), diff는 +/- 색상으로 최대 40줄, 텍스트는 최대 12줄 + "… N lines".
  - `PermissionPrompt`: 4개 옵션을 숫자/문자 키로 선택(y/a/n/N 및 방향키+Enter). 표시 중에는 입력창 비활성.
  - `InputBox`: 여러 줄 입력은 Shift+Enter 대신 `\` 로 끝나는 줄 계속. 히스토리 ↑/↓.
  - `StatusBar`: 모드, 모델, 컨텍스트 사용량(used/size, 퍼센트), 세션 ID 앞 8자, 진행 중이면 스피너.
  - 슬래시 명령: `/mode <id>`, `/model <name>`(목록은 `info.models`), `/sessions`(목록 표시, 선택 시 `--resume` 안내), `/clear`(화면만), `/help`, `/quit`.
  - Ctrl+C: 턴 진행 중이면 `cancel()`, 아니면 두 번 연속으로 종료.
- 테스트: `ink-testing-library`로 ToolCard 상태 렌더링, PermissionPrompt 키 입력 → 핸들러 호출, StatusBar 퍼센트 표시. `SessionHandle`은 테스트용 가짜 구현(이벤트 수동 emit).

## 3. 완료 기준
- `pnpm --filter perdix build && node packages/cli/dist/main.js --cwd <dir>` 로 실제 Python 서버(fake 또는 anthropic)에 붙어 한 턴 완주.
- `perdix -p "..." --json` 이 NDJSON을 출력하고 종료 코드 0.
- 위 테스트 전부 + lint + typecheck 통과.
