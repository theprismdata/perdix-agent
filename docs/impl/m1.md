# M1 구현 스펙: Python 코어 + 헤드리스 ACP 서버

> 설계 근거: [architecture.md](../architecture.md) §6, [harness-loop.md](../harness-loop.md), [protocol.md](../protocol.md). 이 문서는 M1 범위의 모듈 인터페이스를 고정한다. 여기 없는 것은 만들지 않는다.

## 0. 공통 규칙
- Python 3.12, `asyncio`, `pydantic` v2, 타입 힌트 필수, `ruff` + `mypy --strict` 통과.
- 패키지 루트 `server/src/perdix/`. 테스트는 `server/tests/`, `pytest-asyncio` (`asyncio_mode = "auto"`).
- 외부 네트워크를 쓰는 테스트 금지. Anthropic SDK는 `FakeProvider`로 대체한다.
- 공급자 특이사항은 `llm/<provider>.py` 안에만. 하네스/도구에 공급자 분기 금지.

## 1. Phase A1 — 메시지 모델, 투영, 세션 저장소

### `context/messages.py`
```python
class TextItem(BaseModel):        kind: Literal["text"]; text: str
class ToolUseItem(BaseModel):     kind: Literal["tool_use"]; id: str; name: str; input: dict[str, Any]
class OpaqueItem(BaseModel):      kind: Literal["thinking","reasoning","signature"]; provider: str; model: str; raw: dict[str, Any]
AssistantItem = TextItem | ToolUseItem | OpaqueItem

class UserMessage(BaseModel):     role: Literal["user"]; content: list[ContentBlock]; origin: Literal["user","synthetic"] = "user"
class AssistantMessage(BaseModel):role: Literal["assistant"]; items: list[AssistantItem]; provider: str; model: str; stop_reason: str
class ToolResult(BaseModel):      tool_use_id: str; index: int; content: str; is_error: bool = False; display: list[DisplayContent] = []
# ContentBlock = TextBlock | ImageBlock (base64) ; DisplayContent = TextDisplay | DiffDisplay(path, old_text, new_text)
```

### `session/store.py` — SQLite event log
- 파일: 기본 `~/.perdix/perdix.db`, 테스트는 `:memory:` 또는 tmp 경로 주입. `aiosqlite`, WAL, `busy_timeout=5000`.
- 테이블:
  - `meta(key TEXT PK, value TEXT)` — `schema_version`
  - `sessions(id TEXT PK, project_path TEXT, project_hash TEXT, mode TEXT, model TEXT, provider TEXT, created_at REAL, updated_at REAL, title TEXT, permission_rules TEXT)`
  - `events(id INTEGER PK AUTOINCREMENT, session_id TEXT, seq INTEGER, kind TEXT, payload TEXT(JSON), created_at REAL, UNIQUE(session_id, seq))`
  - `fts_events` — FTS5(content=events, columns: text). 텍스트가 있는 kind만 색인.
- `kind` 값: `user_message`, `assistant_message`, `tool_started`, `tool_result`, `permission_decision`, `mode_change`, `config_change`, `compaction`.
- API:
```python
class EventStore:
    @classmethod async def open(cls, path: str | Path) -> "EventStore"
    async def create_session(self, project_path: str, mode: str, provider: str, model: str) -> SessionRecord
    async def get_session(self, session_id: str) -> SessionRecord | None
    async def list_sessions(self, project_path: str | None = None) -> list[SessionRecord]
    async def append(self, session_id: str, kind: str, payload: BaseModel | dict) -> int   # returns seq
    async def events(self, session_id: str) -> list[Event]
    async def update_session(self, session_id: str, **fields) -> None
    async def search(self, query: str, scope: Literal["all","project"], project_path: str | None, limit: int = 20) -> list[SearchHit]
    async def close(self) -> None
```
- 오래된 `schema_version`을 가진 서버는 쓰기 거부(`SchemaTooNewError`).

### `context/view.py` — ModelView 투영 (순수 함수)
```python
class ModelView(BaseModel): messages: list[UserMessage | AssistantMessage | ToolResultsGroup]
def project(events: list[Event], *, provider: str, model: str) -> ModelView
```
규칙(harness-loop.md §5.1):
- `assistant_message`의 OpaqueItem은 `(provider, model)`이 인자와 같을 때만 포함.
- 한 assistant 메시지의 tool_use에 대응하는 `tool_result`들은 `index` 순으로 정렬해 하나의 `ToolResultsGroup`으로 묶는다(와이어 형식은 어댑터 책임).
- `compaction` 이벤트 `{from_seq, to_seq, summary, provider, model}`가 있으면 그 범위의 메시지는 `UserMessage(origin="synthetic", text=summary)` 하나로 치환. provider가 다르면 summary 텍스트만 사용.
- 복구 함수: `def find_unpaired_tool_uses(events) -> list[tuple[ToolUseItem, bool started]]`.

## 2. Phase A2 — LLM 공급자

### `llm/base.py`
```python
class ToolSpec(BaseModel): name: str; description: str; input_schema: dict[str, Any]
class ModelRequest(BaseModel): system: str; tools: list[ToolSpec]; view: ModelView; max_tokens: int; effort: str | None
class ModelEvent: TextDelta(text) | ThinkingDelta(text) | ToolUseStart(id, name) | ToolUseDelta(id, partial_json) | ToolUseEnd(id, input) | Usage(input_tokens, output_tokens, cache_read, cache_write) | Stop(reason: Literal["end_turn","tool_use","max_tokens","refusal","error"], message: AssistantMessage | None, detail: str | None)
class Provider(Protocol):
    name: str
    def sanitize_tool_schema(self, schema: dict) -> dict
    def stream(self, req: ModelRequest) -> AsyncIterator[ModelEvent]
class ProviderError(Exception): retryable: bool; status: int | None
```
- `Stop.message`는 정상 종료 시 완성된 `AssistantMessage`(OpaqueItem에 provider/model/raw 포함). `max_tokens`로 tool_use JSON이 잘렸으면 `message=None`, `detail="truncated_tool_use"`.

### `llm/fake.py` — 테스트용
- 스크립트된 응답 리스트를 받아 순서대로 이벤트를 내보낸다. 호출마다 받은 `ModelRequest`를 기록한다(테스트가 투영 결과를 검사).

### `llm/anthropic.py`
- `anthropic.AsyncAnthropic()` 사용(키는 env). `client.messages.stream(...)`로 스트리밍.
- 요청: `system=[{"type":"text","text":..., "cache_control":{"type":"ephemeral"}}]`, `tools`는 각 ToolSpec + `eager_input_streaming: True`, 마지막 tool 정의에 `cache_control`. `thinking={"type":"adaptive"}`, `output_config={"effort": effort}` (effort 있을 때).
- ModelView → messages 변환: AssistantMessage items를 원래 순서로 content 블록으로. OpaqueItem.raw를 그대로 넣는다. `ToolResultsGroup` → 한 user 메시지, `tool_result` 블록이 content 맨 앞.
- 스트림 이벤트 → ModelEvent. `stop_reason`: `tool_use`→"tool_use", `end_turn`→"end_turn", `max_tokens`→"max_tokens"(tool_use 블록 있으면 `detail="truncated_tool_use"`), `refusal`→"refusal"(stop_details.category를 detail에).
- 예외 매핑: `RateLimitError`, `APIStatusError(>=500)`, `APIConnectionError`→retryable; `BadRequestError` 등→non-retryable.
- `sanitize_tool_schema`: 그대로 통과(Anthropic은 JSON Schema 전체 허용). `additionalProperties`가 없으면 추가하지 않는다.
- 최상위 `fallbacks`는 M1에서 넣지 않는다(설정 옵션으로 M6).

### `llm/catalog.py`
- `ModelInfo(id, provider, context_window, max_output, input_price, output_price, supports_effort)`. 항목: claude-opus-5-5, claude-sonnet-5-5, claude-haiku-4-5 (architecture.md 6.10 기준). `get(model_id) -> ModelInfo`.

## 3. Phase A3 — 도구, 샌드박스, 권한

### `tools/base.py`
```python
class ToolContext: cwd: Path; sandbox: ExecBackend; cancel: asyncio.Event; emit: Callable[[DisplayContent], None]
class Tool(Protocol):
    name: str; description: str; input_schema: dict[str, Any]; kind: ToolKind  # read|edit|delete|move|search|execute|think|fetch|other
    def is_read_only(self, input: dict[str, Any]) -> bool
    async def run(self, ctx: ToolContext, input: dict[str, Any]) -> ToolOutput   # ToolOutput(content: str, is_error: bool, display: list[DisplayContent])
def validate_input(tool: Tool, input: dict) -> list[str]   # jsonschema 오류 메시지. 의존성 추가: `jsonschema`
```
### `tools/registry.py` — `ToolRegistry(tools)`: `get(name)`, `specs() -> list[ToolSpec]`, `read_only_only() -> ToolRegistry`.
### 내장 도구 (M1): `read`(path, offset?, limit?; 줄번호 붙여 반환, 2000줄/50KB 상한), `write`(path, content), `edit`(path, old_string, new_string, replace_all?; old_string 유일성 검사; DiffDisplay 반환), `glob`(pattern, path?), `grep`(pattern, path?, glob?; ripgrep 있으면 사용, 없으면 Python 폴백), `ls`(path), `bash`(command, timeout?=120s; 출력 30KB 상한, 초과 시 꼬리 유지).
- 경로는 `cwd` 기준으로 resolve하고 `cwd` 밖이면 `is_error`. (additional_directories는 M3.)

### `sandbox/base.py`, `sandbox/local.py`
```python
class ExecResult: stdout: str; stderr: str; exit_code: int; timed_out: bool
class ExecBackend(Protocol):
    async def run(self, cmd: str, *, cwd: Path, timeout: float, cancel: asyncio.Event, env_extra: dict[str,str] | None = None) -> ExecResult
```
- `LocalBackend`: `asyncio.create_subprocess_shell(..., start_new_session=True)`, 취소/타임아웃 시 `os.killpg(SIGTERM)` → 2초 → `SIGKILL`.
- **env 정리**: `scrub_env(os.environ)`은 이름이 `*_API_KEY`, `*_TOKEN`, `*_SECRET*`, `PERDIX_SECRET_*`, `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`인 키를 제거. 테스트로 보장.

### `permissions/policy.py`
```python
Decision = Literal["allow","ask","deny"]
class PermissionPolicy:
    def __init__(self, rules: dict[str, Decision | dict[str, Decision]], mode: Literal["interactive","deny","accept-edits","allowlist"])
    def evaluate(self, tool_name: str, input: dict) -> Decision
    def remember(self, tool_name: str, input: dict, decision: Literal["allow","deny"]) -> None   # allow_always/reject_always
DEFAULT_RULES = {"read":"allow","glob":"allow","grep":"allow","ls":"allow","edit":"ask","write":"ask","bash":"ask"}
```
- `bash` 규칙은 명령 프리픽스 글롭(`"git status*": "allow"`). 모드별 변환은 protocol.md §1.3.

## 4. Phase B — 하네스

### `harness/modes.py` — `Mode(id, name, description, read_only: bool, verification: bool)`: chat, plan, build.
### `harness/budget.py` — `Budget(max_steps=200, max_verify_iterations=3, context_ratio=0.75)`; `BudgetExceeded`.
### `harness/hooks.py` — `HookBus` with `pre_tool`, `post_tool` async 콜백 리스트.
### `harness/events.py` — 하네스가 내보내는 내부 이벤트(Union): `TextDelta`, `ThoughtDelta`, `ToolStarted(tool_use_id, name, kind, title, input)`, `ToolRunning`, `ToolFinished(tool_use_id, output)`, `ToolFailed(tool_use_id, reason)`, `PermissionNeeded(tool_use_id, name, input, options) -> awaits decision`, `ContextUsage(used, size)`, `TurnEnded(stop_reason, verification)`.
### `harness/turn.py`
```python
class TurnRunner:
    def __init__(self, *, store, provider, registry, policy, sandbox, budget, hooks, mode, cwd, system_prompt_builder)
    async def run(self, session_id: str, prompt: list[ContentBlock], *, cancel: asyncio.Event, sink: Callable[[HarnessEvent], Awaitable[None]], ask_permission: Callable[[PermissionRequest], Awaitable[PermissionOutcome]]) -> TurnResult   # TurnResult(stop_reason, verification)
```
구현 규칙(harness-loop.md §3):
- 진입 시 `user_message` 이벤트 append. 루프: `project(events)` → `provider.stream` → 이벤트 전달 → `Stop`.
- `Stop(end_turn)`: assistant 레코드 append, 종료(M1은 검증 게이트 없음. `mode.verification`이면 `verification="skipped"` 반환).
- `Stop(tool_use)`: assistant 레코드 append → 도구 실행:
  - 등장 순서로 연속 구간 분할. 읽기 전용 구간(`is_read_only(input)` 전부 참)은 `asyncio.gather(return_exceptions=True)`, 아니면 하나씩.
  - 각 도구: `validate_input` → 실패면 `is_error` 결과. `policy.evaluate` → `ask`면 `ask_permission` 대기(세션당 하나의 큐: 순차 await로 충분). `deny`/거절이면 `is_error("user rejected")`/`is_error("denied by policy")`. `allow_always`/`reject_always`면 `policy.remember` + `permission_decision` 이벤트.
  - `tool_started` append → `pre_tool` 훅 → `tool.run` → `post_tool` → `tool_result` append(`index` 포함).
  - 취소 이벤트가 설정되면 남은 도구에 `is_error("cancelled")` append 후 `TurnResult("cancelled")`.
- `Stop(max_tokens, detail=truncated_tool_use)`: 커밋하지 않고, `max_tokens*2`(상한 128000)로 1회 재시도. 재실패 → `max_tokens`.
- `Stop(max_tokens)` 텍스트만: 커밋 후 synthetic user "계속" 1회 주입.
- `ProviderError(retryable)`: 첫 청크 전이면 백오프 재시도 3회(0.5s, 1s, 2s; 테스트에서는 주입 가능한 sleep). 첫 청크 이후면 보낸 tool_call을 `ToolFailed`로 닫고 `TextDelta("[연결 끊김, 재시도]")` 후 재요청(부분 출력 미커밋).
- `Stop(refusal)`: `TurnResult("refusal")`.
- Step 수 > budget → `max_turn_requests`.
- 매 Step 후 `ContextUsage(used=마지막 usage.input_tokens, size=catalog.context_window)` 이벤트. 압축은 M4.

### `harness/runner.py` — `SessionRunner`: 세션별 `asyncio.Lock`, 취소 이벤트, `TurnRunner` 보유. `prompt()`는 락을 **동기적으로**(`lock.locked()` 검사 후) 잡지 못하면 `TurnBusyError`.

### `context/builder.py` — `build_system_prompt(cwd, mode) -> str`: 고정 지시문 + 작업 디렉터리 + 모드 설명. 지침 파일 로더는 M3. 가변 정보 금지(캐시).

## 5. Phase C — ACP 어댑터와 진입점

### `acp/agent.py` — `class PerdixAgent` implements `acp.Agent`
- `initialize`: `InitializeResponse(protocol_version=..., agent_capabilities=AgentCapabilities(load_session=True, session_capabilities=...list...), agent_info=Implementation(name="perdix", version=__version__))`. `client_capabilities`와 `kwargs`의 `perdix`(=_meta.perdix)를 보관.
- `new_session(cwd, mcp_servers, **kwargs)`: `kwargs.get("perdix")`로 model/mode/permissionMode 덮어쓰기(permissionMode는 argv보다 완화 불가). `EventStore.create_session`. 응답에 `modes=SessionModeState(current_mode_id, available_modes=[chat, plan, build])`, `config_options=[select "model" with catalog entries]`.
- `load_session`: 복구(`find_unpaired_tool_uses` → `tool_result` append) 후 리플레이: user(origin=user)→`update_user_message_text`, assistant text→`update_agent_message_text`, tool_started/tool_result→`start_tool_call`/`update_tool_call`.
- `list_sessions(cwd)`: `EventStore.list_sessions(cwd)`.
- `set_session_mode`, `set_config_option(config_id="model")`: 세션 업데이트 + `current_mode_update`/`config_option_update` 알림.
- `prompt`: `SessionRunner.prompt(...)`. `sink`는 `acp/mapping.py`로 HarnessEvent→SessionUpdate 변환 후 `conn.session_update`. `ask_permission`은 `conn.request_permission(session_id, options=[allow_once, allow_always, reject_once, reject_always], tool_call=ToolCallUpdate(...))`. `outcome.cancelled` 처리. 반환 `PromptResponse(stop_reason=..., field_meta={"perdix": {"verification": ...}})` (SDK 필드명은 `field_meta`, alias `_meta`). 응답/캡 필드는 snake_case 생성자 인자(`load_session=`, `session_capabilities=`, `config_options=`)를 쓴다.
- `cancel`: 알림. 세션의 cancel 이벤트 set.
- `ext_method`/`ext_notification`: M1은 `perdix/diagnostics` 알림만 받아 무시(로그).
- `on_connect(conn)`: 보관.

### `acp/mapping.py` — HarnessEvent → `SessionUpdate` (protocol.md §3 표). ToolKind 매핑: tool.kind 그대로.

### `__main__.py`
- argparse: `--version`, `--db PATH`, `--model`, `--provider anthropic|fake`, `--permission-mode`, `--effort`, `--log-level`. 로그는 **stderr**(stdout은 ACP 전용).
- `asyncio.run(acp.run_agent(PerdixAgent(config), use_unstable_protocol=True))`.
- `--provider fake --fake-script PATH`: JSON 스크립트로 FakeProvider 구동(e2e 테스트용).
