# ADR 0007: Windows 설치 마법사와 초기 설정

상태: 채택

설치 시 API 키 입력, 기본 공급자 선택, 프로그램 설치 및 바로가기 생성을 한 번에 수행한다.
Inno Setup을 사용한 사용자별 설치로 관리자 권한을 요구하지 않는다.
설치 마법사는 키를 가린 입력창에서 받고 기존 credentials.json의 다른 항목을 보존한다.
키는 프로세스 명령행이나 설치 로그에 넣지 않는다. 임시 입력 파일은 처리 후 지운다.
기본 모델은 ~/.perdix/preferences.json의 default_model에 저장한다. CLI는 새 세션에서만
이를 사용하고 명시적 --model이 우선하며, 기존 세션 복구의 모델은 유지한다.
VS Code가 설치되어 있으면 같은 설치 프로그램에 포함한 Webview 확장을 자동 설치한다.
VS Code가 없거나 탐지하지 못하면 CLI 설치는 계속 진행하며 확장 단계만 건너뛴다.
제거 시 프로그램과 바로가기만 삭제하고 사용자의 키와 세션 데이터는 남긴다.
