# ADR 0013: 세션 간 메모리와 기록 검색

상태: 채택 (자동 기록 정책은 [ADR 0014](0014-automatic-memory.md)로 대체)

## 결정

Python 서버가 프로젝트 `.perdix/MEMORY.md`와 전역 `~/.perdix/MEMORY.md`를
공유한다. `memory_read`는 조회, `memory_append`는 사실을 추가한다. 자동 추출은
하지 않고 사용자 요청에 따라 기록한다. 기존 내용은 수정하거나 삭제하지 않는다.
파일 잠금으로 프로세스 간 추가를 직렬화한다. 파일당 64,000자, 추가당 4,000자로
제한하고 프롬프트에는 각 범위의 최신 16,000자만 출처와 함께 넣는다.

매 모델 요청에서 메모리를 다시 읽으므로 새 세션·복구·진행 중 세션이 최신
기록을 참조한다. 메모리는 참고 자료이며 실행 권한이나 프로젝트 신뢰를 넓히지
않는다. 읽기는 기존 읽기 전용 정책, 추가는 기본 ask 정책을 따른다.

`session_search`는 기존 EventStore FTS5 검색을 도구로 노출한다. 기본 범위는
전체 프로젝트이고 project 범위로 좁힐 수 있다. 출처와 세션 ID를 반환하며
대화 원문을 자동으로 새 세션에 복사하지 않는다. ACP 메서드 변경은 없다.
