# ADR 0031: 외부 ACP 에이전트를 같은 게이트웨이에 연결

상태: 채택

## 결정

프로젝트의 선택적 `acp` 설정에 운영자가 지정한 실행 명령 배열과 초기 모드를 둔다.
설정이 없으면 기존 Perdix 서버를 실행한다. Hermes는 `hermes acp`, OpenClaw는
`openclaw acp`로 연결하며 모델·도구·인증·실행 정책은 해당 에이전트가 소유한다.
명령은 셸을 거치지 않으며 텔레그램 요청으로 명령이나 환경변수를 바꿀 수 없다.
자식 환경은 기존 ExecBackend의 `scrub_env`와 채널 비밀 제거 계약을 유지한다.

텔레그램의 `/run 프로젝트 요청`과 마지막 프로젝트 선택을 재사용한다. 같은
운영자의 기존 Hermes 텔레그램 봇과 설정은 변경하지 않는다. 외부 ACP 세션에는
Perdix 전용 `build` 모드나 워크플로 메타데이터 해석을 적용하지 않는다.
외부 에이전트가 제공하는 승인 요청은 기존 대시보드에서 처리하며, 게이트웨이가
에이전트 자체의 권한 정책을 대체하거나 보장하지 않는다.

기록에는 실행 대상의 식별자를 함께 append한다. 기존 레코드는 Perdix로 해석한다.
프로젝트의 실행 대상이 바뀌면 과거 세션 ID를 새 에이전트에 전달하지 않는다.
`session/load` 지원 여부는 initialize 응답으로 확인하고 미지원 시 새 세션을 만든다.
OpenClaw ACP는 별도의 OpenClaw Gateway가 실행 중이어야 한다.
