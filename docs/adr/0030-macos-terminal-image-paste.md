# ADR 0030: macOS Terminal의 이미지 붙여넣기

상태: 채택

## 배경

macOS 기본 Terminal은 이미지 전용 클립보드의 `⌘+V`를 TUI 키 입력으로 전달하지 않는다.
기존 키 처리와 빈 bracketed paste 처리만으로는 스크린샷 붙여넣기를 지원할 수 없다.

## 결정

로컬 macOS Terminal에서 Hermes TUI가 실행되는 동안 클립보드 보조 프로세스를 사용한다.
Terminal이 전면이고 클립보드에 텍스트 없이 PNG·TIFF가 있으면 이미지를 전용 임시 폴더에
저장하고, 기존 이미지 표현을 유지한 채 파일 URL을 텍스트 표현으로 추가한다.
Terminal의 기본 `⌘+V`가 이 URL을 전달하면 기존 파일 드롭 경로가 ACP 이미지 블록으로 변환한다.
키보드 감시, 접근성 권한, Terminal 환경설정 변경은 사용하지 않는다.

클립보드 변경 횟수와 보조 프로세스가 쓴 URL이 일치할 때만 원래 표현을 복원한다.
다른 앱이 전면으로 오거나 Perdix가 종료되면 복원하며, 종료 시 임시 파일도 제거한다.
텍스트 클립보드·원격 세션·다른 운영체제에는 적용하지 않는다.
사용자 명령 목록의 `/paste`는 제거하고 표준 붙여넣기와 `/image`를 제공한다.

## 경계

이 처리는 명시적인 사용자 첨부를 위한 클라이언트 기능이다. LLM·도구·권한 로직과
서버 저장 형식은 변경하지 않으며 기존 ACP `session/prompt` 이미지 블록을 사용한다.
