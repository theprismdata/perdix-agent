# ADR 0016: 요청에 따른 메인 세션 모드 자동 전환

상태: 채택

## 결정

메인 세션 모델에 `switch_mode` 도구를 제공한다. 매 요청에서 질문·설명·조사는
`chat`, 계획만 요청하면 `plan`, 구현·수정·실행 요청은 `build`를 선택한다.
의미 판단은 기존 모델 호출에서 수행하고 별도의 분류 호출이나 키워드 규칙은 추가하지 않는다.
모드가 다르면 작업 전에 전환 도구를 단독 호출한다.

전환은 ACP `current_mode_update`와 기존 append-only `mode_change`로 기록한다.
현재 Turn의 도구 목록과 프롬프트도 즉시 갱신한다. 쓰기·실행 권한 정책과 프로젝트
신뢰 게이트는 유지한다. 하위 에이전트에는 전환 도구를 넘기지 않아 프리셋 권한을 유지한다.

## 한계

요청 의도 판단과 도구 호출은 모델이 수행하므로 모든 표현에서 전환을 보장하지 않는다.
수동 `/agent`·`/mode` 변경도 계속 제공하며 다음 요청의 의도에 따라 다시 전환할 수 있다.
