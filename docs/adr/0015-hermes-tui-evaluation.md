# ADR 0015: Hermes TUI 평가판

상태: 평가 중

## 배경

기존 Perdix 기능을 유지하면서 Hermes의 전체 화면 TUI를 실제로 사용해 평가한다.
기본 TUI 교체와 Hermes 에이전트 코어로의 전환은 이번 범위에 포함하지 않는다.

## 결정

- Hermes의 `ui-tui/src`, 자체 Ink 렌더러, 공통 UI 모듈을 버전 고정한 원본으로 보관한다.
- `packages/hermes-tui`는 원본 UI를 빌드하고 별도 프로세스로 실행한다.
- `perdix --tui hermes`에서만 평가판을 선택한다. 기본 TUI와 헤드리스 실행은 유지한다.
- CLI의 로컬 WebSocket 변환 계층은 Hermes 화면의 JSON-RPC를 기존 Perdix ACP로 변환한다.
  이는 프로세스 내부 UI 연결 계약이며 새로운 Perdix 서버 프로토콜 메서드는 추가하지 않는다.
- 서버의 모델 호출, 도구 실행, 권한 판단, 저장 형식은 변경하지 않는다.
- 연결은 루프백 주소와 실행마다 생성하는 토큰으로 제한한다. UI 프로세스에는
  공급자 키와 기존 Hermes 사용자 설정을 넘기지 않는다.

## 평가 범위

입력, 응답 스트리밍, 도구 결과, 권한 승인, 취소, 새 세션과 저장된 세션 복원을 연결한다.
Hermes 전용 음성·결제·플러그인·설정 기능은 Perdix 기능으로 위장하지 않고 미지원으로 응답한다.
원본 UI의 영어 문구는 평가판에서 유지하며 Perdix 안내는 한국어로 제공한다.
호환 명령은 Perdix 모드·모델·상태·사용량·취소·루프·메모리로 연결한다.
Hermes 자체 의미가 다른 도움말·사용량·저장·중지 처리만 Perdix 연결에서 분기한다.
`/save`는 서버의 자동 저장과 복원 방법을 안내하며 원본 기록을 변경하지 않는다.
`/login`, `/logout`, `/auth status`는 기존 CLI 인증 경로를 사용한다. UI의 Ink 렌더러와
입력을 일시 중단하고 부모 프로세스가 인증 프로그램에 터미널을 넘긴다. 인증 변경 후에는
서버 연결을 새로 열어 저장된 세션을 복원하고 모델·모드는 유지한다. 작업 실행 중에는
인증 변경을 거부한다. 이 연결에는 서버 ACP 확장을 추가하지 않는다.
설치 파일에 동봉하는 작업과 기본 TUI 교체는 평가 후 별도로 결정한다.

## 업데이트

원본 버전·라이선스·파일 목록은 `packages/hermes-tui/UPSTREAM.md`에 기록한다.
원본 변경과 Perdix 연결 코드를 분리해 후속 업데이트의 차이를 비교할 수 있게 한다.

## 검증

실제 Perdix fake 공급자와 ACP를 통한 통합 테스트로 스트리밍·권한·복원을 검증한다.
빌드한 평가판을 PTY에서 구동해 한글 입력, 좁은 화면, 긴 대화와 크기 변경을 확인한다.
