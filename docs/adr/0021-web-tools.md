# ADR 0021: 웹 검색·페이지 조회 도구

상태: 채택

Python 내장 읽기 전용 도구 websearch와 webfetch를 추가한다. 검색은 키 없는
Bing RSS 엔드포인트를 사용하며 제목·URL·요약을 반환한다. RSS 형식 변경·차단은
명시적 도구 오류로 처리한다. 공식 검색 API 연결은 별도 확장 범위다.

페이지 조회는 GET으로 HTML의 본문·링크 또는 텍스트를 반환한다. JavaScript,
로그인, PDF·바이너리는 처리하지 않는다. 응답 크기·시간·리다이렉트 횟수를 제한한다.
웹 응답은 외부 자료이며 지시나 권한 변경으로 취급하지 않는다.

HTTP 연결은 httpx2와 시스템 인증서 저장소 truststore를 사용한다. URL·DNS를
검사하고 공인 IP로 연결을 고정하여 리다이렉트·DNS 재바인딩으로 내부 주소에
연결하지 못하게 한다. TLS 검증은 유지하며 인증 헤더와 비밀 env를 전달하지 않는다.

ACP·히스토리 형식은 유지한다. 도구 등록과 기존 권한 정책으로 모든 공급자 및
메인·하위 에이전트에서 사용할 수 있다.
