# ADR 0014: 유휴 세션에서 자동 메모리 추출

상태: 채택 (ADR 0013의 수동 기록 우선 정책을 대체)

## 결정

메모리는 기본 활성화한다. Python 서버가 시작할 때와 주기적으로 유휴 세션을
검사한다. 기본 유휴 시간은 6시간, 최대 기록 나이는 30일이며 실제 사용자
발화가 2회 이상이고 마지막 응답이 정상 종료된 세션만 처리한다. 실행 중인
Turn은 제외한다. 서버가 꺼져 있으면 다음 기동에서 처리한다.

백그라운드 작업은 도구 없는 공급자 중립 ModelRequest로 대화의 유용한 사실,
사용자 선호, 확정된 결정, 검증된 작업 요령을 JSON으로 추출한다. 사용자·응답
텍스트만 보내며 reasoning, 도구 원문, 이미지, 비밀 값은 제외한다. 별도 세션을
만들거나 사용자 대화를 수정하지 않는다. 추출·통합 결과 모두 스키마를 검사한다.

`~/.perdix/memories/raw/`에 세션 ID·마지막 순서 번호별 추출 결과를 불변 파일로
저장한다. 통합 모델이 같은 범위의 중복·정정을 정리하고 불변 snapshot을
추가한다. 프로젝트 기록은 해당 프로젝트에서만 사용하고 명시적인 사용자
공통 선호만 전역에 넣는다. 파일 잠금, 원자적 공개, 원본 버전 확인으로 재시작,
다중 서버, 처리 중 새 발화를 보호한다. 실패한 통합은 저장된 추출에서 재시도한다.

다음 모델 요청은 최신 snapshot의 관련 프로젝트·전역 기록을 참조한다.
기존 MEMORY.md와 수동 도구는 호환 목적으로 남지만 자동 생성은 프로젝트
파일을 수정하지 않는다. 생성과 사용은 독립 설정이며 세션별 설정 변경은 기존
`config_change` 이벤트로 보존한다. 표준 ACP `session/set_config_option`과
`/memories` 명령으로 제어하고 새 ACP 확장 메서드는 추가하지 않는다.

공급자의 남은 할당량 비율은 현재 공통 인터페이스가 제공하지 않는다.
따라서 비율을 추측하지 않고 호출 시간·출력·처리 세션 수를 제한하고 429에는
백오프한다. 자동 메모리 호출에는 별도 모델을 지정할 수 있다.
