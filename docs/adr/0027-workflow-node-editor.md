# 0027: 워크플로 노드 편집 초안

상태: 구현

## 결정

Gateway의 기존 vanilla SVG 그래프 옆에 별도 노드 편집기를 제공한다. 분석·구현·리뷰 노드와
의존성을 편집하고, 기존 `POST /api/jobs`에 `/workflow plan <JSON>`으로 제출한다.
서버의 WorkflowPlan 검증과 기존 ACP 경로를 재사용하며 새 ACP 메서드는 추가하지 않는다.
이전 실행의 계획·이벤트·검증 결과를 변경하지 않고 매번 새 run을 만든다.

편집은 실행하지 않는다. 계획 생성 후 기존 **계획 실행**을 명시적으로 요청해야 한다.
모델 호출·작업 실행·권한 판단은 기존 Python에 둔다. JS의 검증은 편집 오류 안내일 뿐
실행 권한 판단이 아니며, 서버는 제출된 계획을 독립적으로 검증한다.

## 저장

초안은 `perdixWorkflowDraft:<project>` sessionStorage 키에 버전 1로 저장한다.
저장 값은 `{version:1,plan:<WorkflowPlan>,positions:<taskId별 x/y>}`다. 자격 증명은 포함하지 않는다.
인식하지 못하는 버전·형식은 자동 실행/제출하지 않고 복원 실패를 표시한다.
프로젝트 전환 시 분리하고, 로그인 해제 시 메모리 편집 상태를 비운다.
배치 좌표는 UI 전용이며 실행 계획에 보내지 않는다. 파일·서버 DB 저장 포맷은 변경하지 않는다.

## 범위

노드 추가/속성 수정/배치/연결/삭제, 연결 삭제, 기존 계획 복사, 현재 탭 초안 복원,
순환·누락 검증, 새 계획 제출을 제공한다. 범용 n8n 노드나 임의 코드 실행 노드는 추가하지 않는다.
