# ADR 0022: 자동 컨텍스트 압축

상태: 채택

모델 요청을 만들 때 시스템 프롬프트·도구 스키마·투영 이력의 UTF-8 크기를
2바이트당 1토큰으로 보수적으로 추정한다. 직전 실제 입력 토큰 사용량도 반영한다.
출력 토큰 여유를 포함해 모델 컨텍스트의 75%에 도달하면 compactor 프리셋을 호출한다.

원본은 변경하지 않고 기존 compaction 이벤트를 append한다. 현재 사용자 요청과
마지막 assistant 및 그 도구 결과는 보호한다. 완료된 과거 구간만 선택하며 호출·결과
쌍을 분리하지 않는다. 재압축은 기존 요약을 포함한 투영을 입력으로 사용한다.

요약 호출은 도구 없는 별도 모델 요청이며 역할별 모델·effort를 사용한다. 작은 요약
모델에도 들어가도록 자료를 분할하고 이전 요약을 이어받는다. 호출 횟수·출력·시간을
제한하고 취소 시 요약을 커밋하지 않는다. 공유 목표 예산에 호출을 포함한다.

공급자 오류·빈 요약·거부 등은 도구 결과만 축약하는 결정적 대체 요약으로 처리한다.
대체 요약에서도 사용자 요청과 assistant 본문은 보존한다. 충분히 줄지 않으면 원본
투영을 유지하며, 한도를 초과하는 요청은 전송하지 않고 사유를 반환한다.

메인·하위 에이전트 모두 적용한다. UI에는 기존 ACP 텍스트 진행 알림을 사용한다.
기존 event log·ModelView·ACP 형식은 변경하지 않는다.
