# ADR 0020: 프로젝트 규칙 자동 로딩

상태: 채택

전역 ~/.claude/CLAUDE.md와 cwd의 상위 폴더부터 작업 폴더까지 규칙을 읽는다.
각 폴더에서는 AGENTS.md, CLAUDE.md, .claude/CLAUDE.md, CLAUDE.local.md 순으로
적용한다. 가까운 폴더와 나중 파일이 충돌 시 우선한다. 사용자 요청과 권한 정책은
규칙 파일보다 우선하며 규칙에서 명령을 자동 실행하지 않는다.

CLAUDE 파일의 독립된 @path 줄은 로컬 Markdown 임포트로 처리한다. 임포트는
프로젝트 루트 또는 전역 .claude 폴더 안으로 제한한다. 순환·중복·크기·파일 수를
제한하고 코드 블록 안의 임포트는 실행하지 않는다.

하위 폴더 규칙은 도구의 path를 통해 발견한다. 새로운 하위 규칙이 있으면 쓰기
전에 도구 오류로 규칙 확인을 요청하며 다음 모델 호출의 시스템 프롬프트에 넣는다.
읽기는 허용한다. 매 모델 호출마다 파일을 다시 읽으며 메인·하위 에이전트에 적용한다.

히스토리는 append-only로 유지하며 기존 ACP와 저장 형식은 변경하지 않는다.
