# ADR 0029: 명시적 전체 승인을 위한 yolo 권한 모드

상태: 승인됨

## 배경

도구별·명령별 always 승인은 수정과 실행을 연속 수행할 때 반복 승인을 요구한다.

## 결정

기존 `--permission-mode`에 `yolo`를 추가한다. Python 권한 정책에서 모든 도구를
allow로 판정하며 명시적 deny와 세션 거부 규칙도 우회한다. 기본 모드는 바꾸지 않는다.
서버 시작 인자보다 느슨한 세션 메타데이터는 기존대로 거부하며 yolo를 가장 느슨한
모드로 취급한다. 별도 ACP 메서드나 저장 형식은 추가하지 않는다.

대화형 서버에서는 승인 화면에 세션 전체 승인 선택지를 제공한다. 선택 즉시 현재
정책 객체의 모드를 변경해 이후 도구에도 적용한다. `/permissions`와 표준
`session/set_config_option`의 `permission_mode`로도 사용자 선택을 받는다.
명시적 사용자 선택은 `config_change`의 `permission_mode_selection` 키로 append하고
복원한다. 세션 생성 메타데이터는 계속 완화를 금지하고, 비대화형 제한 모드는
런타임 선택으로도 완화하지 않는다.

## 결과

사용자는 `perdix --permission-mode yolo`로 승인 요청을 생략한다. 입력 검증,
샌드박스, 모드별 도구 제한, 비밀 환경변수 정리 및 프로젝트 신뢰 게이트는 유지한다.
