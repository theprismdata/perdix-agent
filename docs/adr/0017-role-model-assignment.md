# ADR 0017: 메인 모드와 하위 에이전트 모델 사전 할당

상태: 채택

## 결정

기존 `models`·`agents` JSON 형식에 메인 역할 `chat`, `plan`, `build`를 추가한다.
사용자 설정 폴더 `~/.perdix/agents.json`을 자동 로드하며 `--agents-config`가 우선한다.
파일을 찾지 못하면 기존 기본값을 사용하고 잘못된 설정은 시작 오류로 처리한다.

새 세션은 시작 역할의 모델을 사용한다. 명시적 세션 초기 모델은 우선한다.
서버의 `--model`은 역할 할당이 없을 때의 기본값이다.
수동·자동 모드 전환 시 해당 역할의 모델과 effort를 적용하고 ACP
`config_option_update`로 클라이언트에 통지한다. 자동 전환은 현재 Turn의 다음 모델
호출부터 적용한다. 모델 변경은 기존 `config_change`로 append한다.

`/model` 선택은 현재 역할에 적용되고 다음 모드 전환 때 사전 할당이 다시 적용된다.
할당이 없는 역할은 현재 모델을 유지한다. 하위 에이전트의 기존 오버라이드 규칙은 유지한다.
모델 별칭에 명시한 provider는 카탈로그 외 모델의 공급자 선택에도 사용한다.
권한·프로젝트 신뢰 규칙은 바꾸지 않는다.
