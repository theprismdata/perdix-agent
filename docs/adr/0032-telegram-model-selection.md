# ADR 0032: Telegram 대화별 모델 선택

상태: 채택

## 결정

Telegram `/model`은 공통 모델 카탈로그를 페이지·검색으로 보여주고 정확한 모델 ID를
받아 선택한다. 사용자·채팅·프로젝트·에이전트 실행 설정을 키로 모델 선택 이벤트를
gateway.db에 append한다. 기존 작업·대화 기록을 수정하지 않는다.
선택은 제출 시 작업에 스냅샷으로 기록해 이미 실행 중이거나 대기 중인 작업에
소급 적용하지 않는다. 후속 작업은 기존 대화 세션을 복구한 뒤 표준
`session/set_config_option`으로 모델을 적용하므로 대화 내용은 유지된다.

모델 선택은 허용된 사용자·채팅에서만 가능하다. 카탈로그 외 ID는 거절하며
토큰·인증·권한 모드·프로젝트 신뢰를 변경하지 않는다. 외부 ACP 에이전트는
각자의 모델 체계를 사용하므로 이 명령은 현재 Perdix 프로젝트에만 제공한다.

모델 선택 UI는 Telegram inline keyboard를 사용한다. 각 메뉴의 사용자·채팅·
프로젝트와 버튼 동작을 `telegramModelMenu` 이벤트로 저장하고 callback에는
짧은 임의 식별자와 버튼 인덱스만 넣는다. 긴 모델 ID도 callback의 64바이트
한도를 넘지 않으며, 카탈로그 순서가 바뀌어도 다른 모델이 선택되지 않는다.
메뉴는 1시간 후 만료되고 다른 사용자의 클릭은 모델을 바꾸지 않는다.
페이지 이동은 원래 메시지를 갱신하며 성공한 선택은 버튼을 없애고 결과를 표시한다.
