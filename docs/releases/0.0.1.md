# Perdix 0.0.1

멀티 에이전트 작업을 그래프로 확인하고, 격리된 작업 공간에서 구현·검증한 변경을
명시적으로 반영할 수 있는 첫 0.0.1 릴리스입니다.

## 다운로드

- `Perdix-Setup-macos-arm64.dmg`: Apple Silicon, macOS 13 이상. CLI·서버·VS Code 확장 포함.
- `perdix-vscode-0.0.1.vsix`: VS Code 확장. 별도로 설치하면 Perdix 서버가 필요합니다.
- `SHA256SUMS`: 위 파일의 SHA-256 체크섬.

이번 릴리스는 Windows·Intel Mac 설치본을 포함하지 않습니다.
macOS 설치본은 ad-hoc 서명이며 Apple 공증은 받지 않았습니다.

## 주요 변경

- LangGraph 기반 작업 의존성 실행과 작업별 Git worktree 격리.
- 영속 실행 기록·재개·재시도, 검증된 후보의 명시적 수락과 거절.
- Gateway의 팀 작업 그래프와 노드 추가·설정·연결·삭제 편집기.
- CLI·VS Code의 표준 ACP 계획 표시와 `/workflow` 명령 지원.
- Git 저장소 밖에서 계획을 요청하면 일반 분석 프롬프트 사용 방법 안내.

## 사용

일반 코드 구조 분석은 `/workflow` 없이 프롬프트로 요청합니다.
필요하면 `explore 에이전트로 구조를 조사하고 파일·심볼 근거와 함께 분석해줘`처럼 지시하세요.

구현 워크플로는 Git 저장소 루트에서 시작하고, 신뢰된 프로젝트 설정에 검증 명령을 등록합니다.

```text
/workflow plan README의 실행 안내를 보완하고 검증해줘
/workflow start <runId>
/workflow status <runId>
/workflow accept <runId>
```

계획 생성은 실행을 시작하지 않습니다. 실행 완료도 원본 반영을 의미하지 않습니다.
현재 워크플로에는 구현 작업이 최소 하나 필요하며, 분석 전용 그래프는 지원하지 않습니다.
자세한 제약과 Gateway 사용법은 [워크플로 안내](../workflows.md)를 참고하세요.

## 검증

- Python 테스트 179개, CLI 테스트 27개, 초안 편집 로직 테스트 4개 통과.
- 브라우저 테스트 18개 통과. 실제 Gateway·ACP·격리 Git 저장소 통합 시나리오 포함.
- 전체 패키지 빌드·린트·타입 검사와 Python Ruff·mypy 통과.
- DMG 서명 검증, CLI·서버의 0.0.1 버전 출력과 그래프 정적 파일 포함 확인.
- DMG의 실제 서버에서 ACP 자연어 계획 생성·LangGraph 실행·검증·명시적 반영 확인.

모델 호출 검증에는 고정 응답 공급자를 사용했습니다. 실제 모델의 과업 수행 품질이나
사용자 환경의 설치 마법사 전체 동작을 보장하는 결과는 아닙니다.
