# 세션 간 메모리

Perdix는 과거 대화에서 유용한 내용을 자동으로 추출하고 통합해 다음 세션에서
참조한다. “기억해줘” 요청이나 build 모드 전환 없이 동작한다. 기본적으로
자동 생성과 참조가 켜져 있다.

흐름은 `유휴 대화 → 사실 추출 → 중복·정정 통합 → 다음 모델 요청에 반영`이다.
사용자 선호, 프로젝트 규칙, 확정된 결정, 반복 가능한 작업 요령을 기록한다.
단순 대화 전체 복사나 모든 턴 종료 시 즉시 저장은 하지 않는다.

## 처리 시점

서버 시작 시와 60초마다 검사한다. 기본적으로 6시간 이상 유휴 상태이고 최근
30일 이내에 갱신된 세션을 처리한다. 실제 사용자 발화가 2회 이상이고 마지막
모델 응답이 정상 종료되어야 한다. 실행 중, 짧은 대화, 미완료 도구 호출,
생성을 끈 세션은 제외한다. 서버가 꺼져 있으면 다음 실행에서 처리한다.

도구·추론·이미지 원문은 보내지 않는다. 일반적인 키·토큰·비밀번호·개인 키
패턴은 모델 호출 전과 결과 저장 전에 가린다. 추출과 통합은 도구 없는 LLM
호출이며 사용량이 발생한다. 기본적으로 원래 세션의 모델을 사용한다.
호출당 60초·출력 4,096토큰, 검사당 최대 4세션으로 제한한다. 429 응답은
15분간 다음 생성을 미룬다. 남은 할당량 비율은 공급자 공통 API가 제공하지
않아 자동 판단하지 않는다.

## 대화 중 제어

```text
/memories
/memories generate off
/memories use off
/memories generate on
/memories use on
```

설정은 현재 세션에 적용되며 다시 불러와도 유지된다. 생성과 참조는 독립이다.
생성을 꺼도 기존 기록은 사용할 수 있고, 참조를 꺼도 생성은 계속할 수 있다.
표준 ACP `session/set_config_option`의 `configId: memory_generate` 또는
`memory_use`, `value: on|off`로도 제어한다. 서버 설정에서 끈 기능은 세션
설정으로 다시 켤 수 없다.

“저장된 메모리를 보여줘”는 `memory_read`로 자동 메모리도 조회한다.
“이전 세션에서 결정한 내용을 찾아줘”는 별도 `session_search`로 원문을 검색한다.

## 저장소와 설정

자동 메모리는 `~/.perdix/memories/raw/`(세션별 추출·출처)와 `snapshots/`(통합본)에
저장한다. 원본 대화와 과거 추출·통합본은 수정·삭제하지 않는다. 새 snapshot이
최신 뷰를 대체하므로 중복이나 정정을 반영할 수 있다. 처리한 세션·순서 번호로
재시작 중복을 막으며 통합 실패는 기존 추출에서 재시도한다. 처리 중 새 발화가
오면 오래된 결과를 공개하지 않는다.

프로젝트 기록은 해당 프로젝트에서만, 명시적 공통 선호는 전역으로 참조한다.
모델 요청에는 관련 자동 메모리 최대 16,000자를 넣는다. 자동 생성은 프로젝트
파일을 수정하지 않으며 일반 파일 편집 권한이나 신뢰 설정을 넓히지 않는다.

서버 `--memory-config /absolute/path/memory.json`으로 설정을 덮어쓸 수 있다.
CLI에서는 `--server`로 서버 명령을 지정한다.

```json
{
  "enabled": true,
  "generate_memories": true,
  "use_memories": true,
  "min_idle_hours": 6,
  "max_age_days": 30,
  "poll_seconds": 60,
  "max_sessions_per_pass": 4,
  "timeout_seconds": 60,
  "max_tokens": 4096
}
```

선택적으로 `root`, `extract_model`, `consolidation_model`을 지정한다.
전체 기능은 `enabled: false`로 끈다. `fake_script`는 fake 공급자 검증용으로,
일반 대화 스크립트와 별도 응답을 사용한다.

기존 `.perdix/MEMORY.md`, `~/.perdix/MEMORY.md`와 `memory_append`는 호환용으로
유지한다. 이 수동 도구는 기존 권한 검사를 거치며 자동 생성과 별개다.

설계 결정: [ADR 0014](adr/0014-automatic-memory.md).
