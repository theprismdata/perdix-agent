Perdix 처음 시작하기 (Windows)

설치 프로그램을 받은 경우 (권장)
1. Perdix-Setup-windows-x64.exe를 더블클릭하세요.
2. 설치 위치와 사용할 AI(Claude 또는 OpenAI)를 선택하세요.
3. API 키를 붙여 넣고 '설치'를 누르세요. 이미 저장된 키는 입력을 비워 유지할 수 있습니다.
4. 기본 모델, 키 파일, 바탕화면/시작 메뉴 바로가기가 자동으로 설정됩니다.
5. 완료 화면에서 'Perdix 실행'을 선택하세요. JSON 파일을 직접 만들 필요가 없습니다.
프로그램 제거는 Windows 설정의 '설치된 앱'에서 할 수 있습니다. 키와 대화 기록은 보존됩니다.

설치 후 키를 바꾸려면 바탕화면의 'Perdix 키 설정'을 더블클릭하세요.
   메모장에 아래 구조가 나타납니다. 사용할 공급자의 빈 따옴표 사이에 본인의 API 키를 넣으세요.

{
  "anthropic": {
    "api_key": ""
  },
  "openai": {
    "api_key": ""
  }
}

Claude를 쓴다면 anthropic의 api_key에 넣습니다. 입력 예:
  "api_key": "여기에_본인의_실제_API_키"
위 예시 문구 자체를 넣는 것이 아니라 발급받은 키를 붙여 넣으세요.
사용하지 않는 공급자의 값은 빈 따옴표 그대로 둡니다.
따옴표, 쉼표, 중괄호는 지우지 말고 Ctrl+S로 저장한 뒤 메모장을 닫으세요.
ChatGPT/Claude 로그인 비밀번호가 아니라 해당 공급자가 발급한 API 키를 사용합니다.

바탕화면의 'Perdix'를 더블클릭하세요. 기본 모델은 설치할 때 선택한 공급자에 맞춰 설정됩니다.
   공급자를 바꾸려면 Perdix 입력창에서 /model을 입력하고 원하는 모델을 선택하세요.
   이미 실행 중이었다면 종료한 뒤 다시 실행하세요.

키 파일 위치: C:\Users\사용자이름\.perdix\credentials.json
기존 파일과 키는 덮어쓰지 않습니다. 키가 담긴 파일을 다른 사람에게 보내지 마세요.
credentials.example.json은 빈 입력 예시이며 실제 키는 위 사용자 폴더의 파일에 저장합니다.

다른 프로젝트에서 실행하기

설치 폴더의 perdix.exe에 --cwd 옵션으로 프로젝트 폴더를 지정할 수 있습니다.

현재 서버의 Unix 셸 명령과 프로세스 그룹 취소에는 Windows 호환성 제한이 있습니다.
